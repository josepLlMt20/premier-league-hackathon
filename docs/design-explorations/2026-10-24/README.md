# Fan viewer style exploration

Three generated visual mockups of the existing fan viewer layout, saved for remote viewing and comparison. These are design proposals, not screenshots of the implemented application. No direction has been selected yet.

1. `01-noche-de-partido.png` — dark broadcast styling, lime accents.
2. `02-tribuna-editorial.png` — warm paper, editorial typography, green and orange.
3. `03-club-electrico.png` — light canvas, cobalt and amber sports graphics.

The current application remains unchanged. Match data shown in these concepts is synthetic.
