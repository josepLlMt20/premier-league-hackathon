# Touchline — provisional identity

The user rejected MatchContext and its generic football logo, then asked for an English-based name. Touchline is the implementation's provisional visible identity; it has not been presented as a final naming decision.

- Concept: **sequence / reveal**. Three offset bands and an aperture connect the idea of events, a selected moment and explanation.
- Primary lockup: generated sequence mark next to the readable Touchline wordmark in self-hosted IBM Plex Sans, weight650 with tight tracking.
- Mark source: `web/public/brand/sequence-mark.png`, built-in Image Gen, transparent PNG. It is used directly as a raster asset, including favicon/apple-touch references; no hand-traced SVG substitute.
- Wordmark: `web/src/brand.ts` centralizes the runtime identity. HTML title is in `web/index.html`.
- Colors: petrol mark #135B66; ink text #17252E; canvas #F2F5F6. Keep the mark monochrome. If a dark lockup is needed later, a dedicated reversed asset must be prepared before using it; the current application only has a light header.
- Clear space: at least one-quarter mark width. Current header uses a44px image canvas including internal clear space; mobile36px.
- Minimum mark size:24px recommended in product UI; favicon uses the same bold silhouette. No real club/league marks.
- This delivery does not include a final vector brand package or social campaign. Naming and final brand assets can follow the user's review of the working screen.

## Asset prompt

Create one original minimalist abstract LOGO MARK ONLY on a genuinely transparent background, square1:1 canvas, tightly framed with the mark occupying roughly80% of the canvas. No text, letters or wordmark. Concept sequence/reveal: three confident solid horizontal dark petrol segments, slightly staggered, interrupted by a precise negative-space vertical aperture. Bold and identifiable at24px and16px. Flat #135B66 monochrome, no generic football, sparkle, robot or play icon, no gradients, shadow or3D.
